Z-Axis Behaviour:

  - Increasing position = moves TOWARD the optical bench (closer, collision risk)
  - Higher native unit values = closer to the bench = more dangerous

================================================================================
SCAN STRATEGY
================================================================================

Direction:    Bottom-left → Top-right (recommended and agreed)
Pattern:      Serpentine / boustrophedon
  - Even rows: X sweeps left → right
  - Odd rows:  X sweeps right → left
  - Y always steps upward (one direction only, best for accuracy)

Current scan_tester1.py behaviour:
  - Homes all axes to (0, 0, 0)
  - Moves Z to FOCUS_MM
  - Scans from (0, 0) to (WIDTH_MM, HEIGHT_MM)
  - Returns X and Y to origin when done

PROBLEM: The script currently scans from home (0,0), NOT from the actual
position of the target. It needs to be updated to scan between user-defined
start and end positions (see TO-DO below).
