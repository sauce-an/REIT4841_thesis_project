HARDWARE SETUP
================================================================================

Devices:        3x Zaber T-LSM050A (50 mm travel, linear stage)
Device ID:      6210 (all three)
Firmware:       5.35
Protocol:       Binary
Serial Port:    COM5
Connection:     Daisy-chained via USB

NI DAQ Setup (USB-6451 / Dev1):
  Channel 7  (Dev1/ai7)  → Laser Terminal AC-Coupled LFI Signal
  Channel 15 (Dev1/ai15) → Optical Chopper Sync Signal (~800 Hz)

Device Address Mapping (UPDATED after realignment):
  Address 4 → Y-axis (Up/Down)
  Address 5 → Z-axis (Forward/Backward / Focus)
  Address 6 → X-axis (Left/Right)

Z-Axis Behaviour:
  - Homing (position 0) = moves AWAY from the optical bench (retracted, safe)
  - Increasing position = moves TOWARD the optical bench (closer, collision risk)
  - Higher native unit values = closer to the bench = more dangerous

IMPORTANT: Always close Zaber Console before running any script!

Optical Setup & Polarization Feedback Configuration:
  - Feedback Regime: Maximum feedback mode across previous scans.
  - Quarter-Wave Plate (QWP): Set to NOT filter out any of the specular reflection.
  - Linear Polarizer: Configured to allow full transmission of retro-reflected feedback without attenuation.

================================================================================
SCAN STRATEGY
================================================================================

Direction:    Bottom-left → Top-right (recommended and agreed)
Pattern:      Serpentine / boustrophedon
  - Even rows: X sweeps left → right
  - Odd rows:  X sweeps right → left
  - Y always steps upward (one direction only, best for accuracy)

Current scan_tester1.py behaviour:
  - Homes all axes to (0, 0, 0)
  - Moves Z to FOCUS_MM
  - Scans from (0, 0) to (WIDTH_MM, HEIGHT_MM)
  - Returns X and Y to origin when done

PROBLEM: The script currently scans from home (0,0), NOT from the actual
position of the target. It needs to be updated to scan between user-defined
start and end positions (see TO-DO below).
